# vvEzRapper(README.md只今加筆修正中)
[VOICEVOX](https://voicevox.hiroshiba.jp/)使ってラップ音声を作る。

## 背景

- StudioOneで曲作ってると、時々VOCALOIDでラップや掛け声入れたくなることがある
- ラップや掛け声は、歌と違って音程感はないほうがリアル、むしろ**音程感皆無**にしたい
- そのかわり**リズムはドンピシャ**でオケに合わせたい
- VOCALOIDで音程感なくすためには、面倒なマウス操作が必要
  - ピッチベンドの数値をマウスでいじる
  - 数値入力じゃないので再現性に難がある
  - G.C.M Recordsの[ボカロにラップさせる調声手法。抑揚のつけ方やパラメータ設定を紹介します](https://www.gcmstyle.com/howto-rap-vocaloid/?fbclid=IwY2xjawIHH8dleHRuA2FlbQIxMQABHX8651ttdywkLj4I4yZkt9g_4TZTpWhU73mDgmBcLXVytAdezE64SxujZg_aem_9sYaPvC5wf8X0glAEGVAuA#%E5%9F%BA%E6%9C%AC%E6%96%B9%E9%87%9D%E3%80%8C%E3%81%99%E3%81%B9%E3%81%A6%E3%82%92%E3%83%94%E3%83%83%E3%83%81%E3%83%99%E3%83%B3%E3%83%89%E3%81%A7%E8%A1%A8%E7%8F%BE%E3%80%8D)に実際の手順が書いてある
- 一方読み上げソフトだと音程はないが一つ一つの音の長さを調整する方法がない
- ざっと探してみたところ、ラップ作成アプリはみつからない
- **自分で作るしかない!!**

## VOICEBOX Engineを採用することにした理由

- 音源どうする？

  - 英語を視野に入れてGoogle読み上げて音声データ化
    - 音の長さをコントロールできなさそうなので不採用
    - 英語はあきらめる
  - 他の音源を調査していると、英語と日本語の違い、モーラと音節、等についていろいろ知恵を付ける
  - どうも日本語はモーラ単位で発音、しかも発音時の１モーラの長さは比較的一定だという事がわかる
    - 短めの論文のようなものを見つけた（あとでURL貼る）
  - 日本語一択
    - 自分が使う掛け声やラップは当面日本語
    - どうしても英語ラップがやりたいならカタカナ英語になることは覚悟する

- 音の長さをどうやってコントロールする?

  - アイウエオ音声データ作ってくっつけるのはやりたくない
    - 自分には多分無理
    - スキルあったとしても**めんどくさい**
    - 絶対**車輪の再開発**になる（誰かが作ってる）
  - 読み上げソフト調査時にお試しで使ったVOICEBOXを改めて調査
    - 日本語オンリーで問題なし
    - アクセントとか区切りをマウス操作で調整するGUIがすでに用意されている
    - 音声作成エンジンへのアクセス方法が**オープン**になっているので、GUIに成りすましていろいろな音声が自分で作れそう
    - GUIが出力するプロジェクトファイルが**JSON形式**で、**音声作成エンジンへPOSTする内容(ほぼ)そのまんまの形式**になっている
- **[VOICEVOX](https://voicevox.hiroshiba.jp/)採用！**

## やること頼むこと

- VOICEVOXに頼みたいこと
  - ひな形になるプロジェクトファイルの作成
    - セリフとなるテキスト入力
    - 区切り、アクセントの指定

- vvEzRapperでやること
  - プロジェクトファイルを書き換える
  - 指定したBPMをもとにWaveファイルの長さが丁度よくなるような数値を見つける
    - VOICEVOX Engineで試作WAVEデータ作ってみる
    - **只今いろいろ実験中**

  - プロジェクトファイルの数値を書き換える
