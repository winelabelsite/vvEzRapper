# vvEzRapper(加筆修正中)
VOICEVOX使ってラップ音声を作る。

## 背景

- StudioOneで曲作ってると、時々VOCALOIDでラップや掛け声入れたくなることがある。
- ラップや掛け声は、歌と違って音程感はないほうがリアル、むしろ**音程感皆無**にしたい
- そのかわり**リズムはドンピシャ**でオケに合わせたい
- VOCALOIDで音程感なくすためにどうするかというと、面倒なマウス操作が必要
  - 数値入力じゃないので再現性に難がある
  - (操作法説明しているURL)
- 一方読み上げソフトだと音程はないが音符の長さをコントロールできなさそう
- ざっと探してみたらラップ作成アプリはどうやらなさそう。
- **自分で作るしかない!!**

## VOICEBOX Engineを採用することにした理由

- 音源どうする？

  - 英語を視野に入れてGoogle読み上げて音声データ化
    - 音の長さをコントロールできなさそうなので不採用。
    - 英語は視野にいれるのやめる
  - 他の音源を調査していると、英語と日本語の違い、モーラと音節、等についていろいろ知恵を付ける
  - どうも日本語はモーラ単位で発音、しかも発音時の１モーラの長さは比較的一定だという事がわかる
    - 短めの論文を見つけた
  - 日本語一択
    - 掛け声やラップは日本語だけだと思う
    - どうしても英語ラップがやりたいならカタカナ英語になることは覚悟する

- 音の長さをどうやってコントロールする?

  - アイウエオ音声データ作ってくっつけるのはやりたくない
    - 自分には無理
    - 絶対車輪の再開発になる（誰かが作ってる）
  - 読み上げソフト調査時にお試しで使ったVOICEBOXを改めて調査
    - 日本語オンリーで問題なし
    - アクセントとか区切りを指定するGUIはすでに用意されている
    - 音声作成エンジンへのアクセス方法が**オープン**になっているので、GUIに成りすましていろいろな音声が自分で作れそう
    - GUIが出力するプロジェクトファイルが**JSON形式**で、**音声作成エンジンへPOSTする内容(ほぼ)そのまんまの形式**になっている

  **色々な事をVOICEVOXに頼むことにする！**
